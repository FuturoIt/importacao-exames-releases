# Importar Exames: releases

Repositório **público** com as versões **assinadas pela Mozilla** da extensão FuturoIT "Importar Exames" para Firefox, e o `updates.json` que o Firefox consulta para se atualizar sozinho.

- O código fica no repositório privado `FuturoIt/importacao-exames`.
- Os arquivos daqui são gerados automaticamente pelo workflow **Publicar**. Não edite à mão.
- Instalação: https://github.com/FuturoIt/importacao-exames-releases/releases/latest/download/importar-exames.xpi

Nenhum dado de cliente ou paciente fica neste repositório.
